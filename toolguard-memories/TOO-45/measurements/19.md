## CORRECTION — P2 does occur in the field, benignly, and I said otherwise

I reported the genuine field count as "effectively zero". **A golden record contradicts that**, found while reviewing the fix's corpus diff:

```
before: TG_ATTEST_READONLY=1 uv run python - __HEREDOC_TO_python3__
after : TG_ATTEST_READONLY=1 uv run python - __HEREDOC_TO_python__
```

An earlier clause, `python3 --version >/dev/null 2>&1`, **stole the sink** from a later `uv run python` heredoc. That is P2, in a real command run for real work — not a ticket-19 probe. Dogfood, so still not featherhill-grade evidence.

**It was harmless here because both sinks were foreign**, so the floor rose either way; only the sentinel label was wrong. **P2's damaging variant needs a bash-family token stealing from a foreign sink, and that remains at zero occurrences in all three corpora.**

So the honest statement is: **the P2 mechanism demonstrably fires in real traffic; the harmful direction of it has never been observed.** That is a stronger warrant for the fix than "zero", and weaker than "it was happening to us" — and the difference only became visible because the fix's own corpus diff exposed it.

**Generalisable**: a corpus golden diff is an independent exposure measurement, available *after* a fix and not before. Worth reading as evidence in every ticket that touches decomposition, not merely as a sign-off chore.
