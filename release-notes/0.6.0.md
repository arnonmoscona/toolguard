# toolguard 0.6.0 -- 2026-08-21

Covers TOO-45: an architectural cleanup that turned into a bug hunt. Most of what follows was found by executing the code's own comments and measuring its own claims, not by anything failing in the field.

**Read the two behaviour-change sections first.** This release both tightens and loosens matching, in each case to match what Claude Code itself does or to close a way a rule could silently not apply.

## Commands that are now ALLOWED where they were not

- **The wrappers Claude Code strips, toolguard now strips too.** A rule like `Bash(npm test *)` matches `timeout 30 npm test`, exactly as it does in Claude Code. The set is `timeout`, `time`, `nice`, `nohup`, `stdbuf`, `command`, `builtin`, `noglob`, and **bare** `xargs` -- not `command -v`, not `nocorrect`, not `xargs` with a flag, and not `sudo` or `env`, which Claude Code does not strip either. Verified against the published documentation on 2026-08-21 and recorded with that date, because this mirrors a specification that changes.

  This matters beyond convenience: `auto_migrate` keeps importing rules Claude Code wrote, and until now a migrated rule silently stopped covering commands it covered on the other side of the boundary.

## Commands that now ASK or DENY where they were allowed

- **Foreign code inside a command substitution raises the ASK floor.** `echo $(python -c "...")` now prompts, as `python -c "..."` already did. `echo $(ls -la)` is unaffected -- the floor follows the *content*, not the shape. Measured against real logs: 2 of roughly 26,400 distinct commands newly ask.
- **A heredoc is classified by the statement it belongs to.** `bash -c "true" && python <<EOF` no longer treats `bash` as the heredoc's sink and splice the Python body in as shell. The same held for `;`, `||` and a lone `&`.
- **A malformed permissions list is now a parse failure.** A list written as a bare string -- `deny = "Bash(rm:*)"` instead of `deny = ["Bash(rm:*)"]` -- used to be silently discarded. In the `deny` direction that removed a restriction with nothing to show for it. Such a config now trips the safety floor that clamps governed decisions to `ask` until it is fixed.
- **A malformed `[hard_deny]` entry is reported.** It had no validation at all; a bad entry vanished from the unoverridable layer without an error, a warning, or a log line.
- **A leading environment assignment no longer hides a command from a deny rule**, and a tilde-spelled command no longer walks past a rule written with an absolute path. Both directions of the same spelling now match.
- **A colon is only a wildcard at the end of a pattern**, matching Claude Code. `Bash(git:* push)` treats the colon literally, as documented.

## The maintenance tool stops claiming more than it checked

- **A consolidation now says whether it was actually verified.** The safety gate returned one value for "a corpus was replayed and nothing changed" and for "no corpus was supplied, so nothing was checked". The `--apply` preview and the JSON both now carry `SAFE`/`UNSAFE`/`UNVERIFIED`, and the `--apply` help no longer describes proposals as replay-verified when no replay ran.
- **Static subsumption stops asserting what it never established.** It treated a `/` as a token boundary, so `/usr/bin` appeared to cover `/usr/bin/env` -- and removing the covered rule lost a real permission. Its rationale text no longer claims every command matched by the removed rule is matched by the survivor.
- **The redundancy report stops saying a rule "can be dropped."** With an intervening deny between two copies, dropping the copy it called redundant changed the decision. The note now states what was actually checked and says plainly that it is not a full safety check.
- **A proposal's caption is checked against the change it enacts.** A proposal captioned "tighten Bash" could enact a `Read` broadening to `/**`, because nothing compared the description with the edits.

## Reliability

- **An empty tool registry now fails closed.** A corrupted installation left the hook permitting everything, including past `hard_deny`.
- **An interrupted write no longer makes the decision ledger unreadable.** It is written atomically; previously a truncated file raised on every subsequent read.
- **A declined auto-migration says which kind of declined.** Four distinct lock failures collapsed into one, so a platform with no advisory-lock support was told "another migration is already running" -- and had its once-daily attempt consumed -- every day, forever.
- **The takeover notice routes through the error reporter** rather than writing straight to stderr.

## Under the hood

- **Claude Code's own vocabulary now lives in one module.** `toolguard/claude_code_contract.py` holds the hook wire protocol, the stripped-wrapper list, and the payload field names, each dated. The point is the import edge: whether a module depends on someone else's specification is now visible to static analysis and to a reviewer. See [Architecture, as built](../docs/architecture-as-built.md).
- **The permission engine no longer recovers facts by parsing its own prose.** A fallback outcome was classified by substring-matching the sentence the program had just rendered. The fact is carried instead.
- **Ambient state -- home, cwd, the environment -- is read through one door**, and a runtime guard now catches a relative path resolved against the process's working directory. That guard found a live instance on the permission-decision path on its first run.

## Notes

The test suite is 3,966 tests, up from 3,628. Some of that is new coverage; some is tests that could not previously fail being made able to.
